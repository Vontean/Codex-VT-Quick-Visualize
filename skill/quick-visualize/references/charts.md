# Shared chart presentation

在生成或修改 Line、Grouped Bar、Donut、Radar 和增强 Mermaid 时读取。本文件拥有共享样式与交互规则；数据约束和图型专用语义由对应 reference 拥有。

## Layout and text

- 顶部留白32px，标题至绘图区32px。单行标题与可见容器居中；多行标题左对齐，窄转宽恢复单行时恢复居中。图表标题16px/24px。
- 可容纳画布居中；超宽绘图区保留可读尺寸、左端可达及水平滚动。标题留在可见容器内。Journey 将参考轴与步骤区整体居中；Mindmap 保留根节点初始视野，左右内容均可滚动访问。
- 数据图例在绘图区下方，间隔20px。一行居中；换行后单列居中、项内左对齐；长名称省略并保留完整可访问文本及title。
- 图内文字按真实字体测量，超过可用宽度才换行；独立内容行使用自己的高度。保留语义形状、方向、端点、原始数值与单位。
- 节点包含层从叶节点向外按背景／18% muted混背景交替；深浅主题分别校准对比。

## Details

- 浮层补充当前图面不可见的信息，完整名称和精确值可通过hover或键盘读取。身份、关系和说明分层呈现。
- 表面使用`--popover`；深色向`--popover-foreground`混入6%。主文字使用`--popover-foreground`，名称使用`--muted-foreground`，数值使用主文字色、500字重及等宽数字。
- 1px `--border`、12px圆角、12×14px内距。标题14px/20px、500字重；正文12px/18px。标题与条目组间12px，行间4–6px。浅色阴影为前景色9%，深色为黑色50%。
- 浮层140ms淡入并从.97浮起；立即隐藏，相邻对象可直接接替。reduced-motion关闭过渡。定位坐标使用浮层实际offsetParent，保持完整文本可达。
- 局部详情优先保持与触发对象的关联，再在附近避让。通用节点详情使用最多32px的近候选；独立图型按自身几何避让，不把气泡送到容器远端。
- Radar：默认／选中／其他填充14%／24%／3%；非活动描边和点.10，图例.32。先排除覆盖指针的候选，优先32px以内；受边缘限制时取最近可用距离+16px，最后比较选中多边形、其他图形和标签遮挡。通用绘制与预设采用同一规则。

## Motion and readiness

- 入场使用`cubic-bezier(.23,1,.32,1)`；同批延迟与持续时间同比压缩，总预算≤1200ms。节点从.92淡入，柱形保留单轴生长；D3/rAF几何动画用同一进度曲线。通过显式调用接入。
- 完整退出后20%重入或文档可见性恢复可重播；普通hover和resize不重播。reduced-motion呈现最终状态。
- 流程hover可完成尚未结束的入场，再处理当前对象。共享层的停稳与退出缓冲不替代各图型的语义交互。
- 加载点阵在实际初始化完成后结束，无最短展示时间。Mermaid首次渲染要等待根元素`qvReady`完成，再核对最终`data-state`、loading、可见内容及错误；`enhanced`单独不能证明成功。
- 共享CSS在root外，预设替换innerHTML后仍存在。原生Mermaid回退保留其SVG与视口行为；增强图的展开、返回与Gantt例外见[Mermaid](mermaid.md#presentation)。
