# 验证记录索引

本目录保存一次任务的环境、输入、结果及验证限制。记录描述当时状态，保留历史事实；当前产品契约以[SKILL及其references](../../skill/quick-visualize/SKILL.md)为准。

- [技能文档与Module职责审查](skill-maintenance/RESULT.md)：最新文档归属、结构结论及本机同步。
- [画布与标题对齐](mermaid-polish/alignment/RESULT.md)：对齐规则的宽窄、主题与长标题验证。
- [Mermaid产品规则回迁](mermaid-polish/RESULT.md)：38条产品规则及初次迁移验证。

安装清单只证明该记录对应的版本；当前版本使用最新任务的清单。旧截图、临时profile、浏览器端口、插件缓存路径和窗口保留说明均不是当前环境的保证。源码变更的浏览器验证不代替用户在真实宿主中的视觉验收。

[早期设计与独立review](../../Progress/mermaid/)是历史过程材料；其中的任务清单、等待选择或批准结论只对应当时轮次，不用作当前阻塞项或产品规范。
